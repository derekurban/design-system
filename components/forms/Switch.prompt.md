Switch turns a setting on or off with immediate effect; use Checkbox instead when changes wait for a Save.

```jsx
<Switch label="Weekly digest" description="A summary of new notes every Monday." defaultChecked />
<Switch checked={dark} onChange={setDark} aria-label="Dark theme" />
```

- 36×20 track on `--sunk`; on state uses accent-subtle track and an accent thumb, echoing the logo’s green closing bracket.
